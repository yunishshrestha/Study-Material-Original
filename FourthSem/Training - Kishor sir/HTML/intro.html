Introduction to CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the presentation of a document written in HTML or XML. CSS allows you to control the layout, colors, fonts, and overall appearance of your web pages.

With CSS, you can separate the content of your web page from its presentation. This means that you can write your HTML to structure your content, and then use CSS to style it without having to change the HTML. This separation of concerns makes it easier to maintain and update your web pages.

How CSS Works

CSS works by applying styles to HTML elements. You can target specific elements using selectors, and then define the styles you want to apply to those elements. For example, you can change the color of all paragraphs to blue by using the following CSS:

        p {
            color: blue;
        }

In this example, the selector is "p", which targets all paragraph elements. The declaration block contains the property "color" and its value "blue". This means that all paragraphs on the page will be displayed in blue.

Basic Syntax

The basic syntax of CSS consists of a selector, followed by a declaration block enclosed in curly braces. The declaration block contains one or more declarations, each consisting of a property and a value, separated by a colon. Declarations are separated by semicolons.

        selector {
            property: value;
            property: value;
        }

For example, to change the font size and color of all headings, you can use the following CSS:

        h1 {
            font-size: 24px;
            color: green;
        }
        h2 {
            font-size: 20px;
            color: orange;
        }

In this example, the selector "h1" targets all level 1 headings, while "h2" targets all level 2 headings. The declarations specify the font size and color for each type of heading.
